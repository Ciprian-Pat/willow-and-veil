# Willow & Veil: website proof of concept

Luxury bridal hair and makeup, Austin, Texas.

## View the site

Open this link. A complete copy of the website builds itself in your browser in under a minute. Nothing is installed on your computer.

**https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/Ciprian-Pat/willow-and-veil/main/blueprint.json**

Notes for reviewers:

- This is a private preview running entirely in your browser. Any edits you make are lost when you close or refresh the tab.
- To try the editor, go to `/wp-admin/` in the Playground address bar and sign in with the Playground demo account (username `admin`, password `password`).

## What is in this repository

| File | Purpose |
|---|---|
| `blueprint.json` | Instructions WordPress Playground follows to build the site: install the theme, import images, create pages and menu. |
| `willow-and-veil.zip` | The Willow & Veil WordPress theme, including every site image. |
| `images/` | Full-size site images, used when importing `willow-and-veil-content.xml` on live hosting. |
| `willow-and-veil-content.xml` | WordPress content export for moving to live hosting. |
